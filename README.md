# ياسو المزة — Scheduled Messages

تطبيق أندرويد: تحدد اليوم + الوقت + نص الرسالة، والتطبيق يعرضها تلقائيًا في وقتها.

- بدون إنترنت، بدون حساب، كل البيانات محفوظة محليًا على الجهاز.
- تصميم Glassmorphism بهوية بصرية أصلية (زهرة الياسمين، تدرّج بنفسجي/ذهبي).
- 3 أيقونات تطبيق قابلة للتبديل من داخل التطبيق (ياسمين، هلال ونجمة، قلب).
- الوقت الحالي في الأردن وسوريا بالعلمين الرسميين، في الشاشة الرئيسية وفي الـ Widget.
- منتقي وقت عصري بأسلوب العجلة الدوارة (Wheel Picker).
- نافذة تأكيد قبل حذف أي رسالة.
- Widget للشاشة الرئيسية بـ 3 مقاسات متجاوبة (صغير/متوسط/كبير)، يتحدّث تلقائيًا.
- يعمل تلقائيًا بعد إعادة تشغيل الهاتف.
- دعم كامل للعربية وواجهة RTL.

## طريقة 1: البناء عبر Android Studio (موصى بها)

هذه أسهل طريقة وتعطيك تحكمًا كاملاً (تشغيل مباشر على هاتفك، تعديل الكود، إلخ).

### المتطلبات
- تثبيت [Android Studio](https://developer.android.com/studio) (الإصدار الأخير، يشمل JDK وAndroid SDK تلقائيًا).

### الخطوات
1. فك ضغط مجلد المشروع `ReminderMessages` في أي مكان على جهازك.
2. افتح Android Studio، اختر **Open**، ثم اختر مجلد `ReminderMessages`.
3. سيظهر شريط أعلى الشاشة يطلب **"Sync Now"** — اضغط عليه. (هذه الخطوة تحتاج إنترنت لديك؛ ستقوم تلقائيًا بتنزيل ملف `gradle-wrapper.jar` الثنائي الوحيد الناقص، بالإضافة إلى كل اعتماديات المشروع). انتظر حتى تكتمل المزامنة (قد تستغرق بضع دقائق أول مرة).
4. لتشغيل التطبيق مباشرة على هاتفك أو محاكي: اضغط زر **Run ▶** في الأعلى.
5. لإنتاج ملف APK فعلي:
   - من القائمة: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
   - بعد الانتهاء، ستظهر رسالة بها رابط **locate** يفتح مجلد الملف الناتج مباشرة.
   - المسار عادة: `app/build/outputs/apk/debug/app-debug.apk`.
6. انسخ ملف الـ APK إلى هاتفك (عبر كابل USB، بلوتوث، أو رفعه لتطبيق تخزين سحابي) وثبّته. قد تحتاج تفعيل خيار "تثبيت من مصادر غير معروفة" في إعدادات الهاتف.

## طريقة 2: بناء تلقائي في السحابة عبر GitHub Actions (بدون تثبيت أي شيء)

المشروع يحتوي على ملف جاهز: `.github/workflows/build-apk.yml`. هذا يجعل GitHub يبني الـ APK لك تلقائيًا على خوادمه.

### الخطوات
1. أنشئ حساب على [github.com](https://github.com) إن لم يكن لديك واحد (مجاني).
2. أنشئ مستودع (Repository) جديد فارغ.
3. ارفع محتويات مجلد `ReminderMessages` بالكامل إلى هذا المستودع. أسهل طريقة بدون سطر أوامر:
   - افتح صفحة المستودع على GitHub.
   - اضغط **Add file → Upload files**.
   - اسحب كل محتويات المجلد (بما فيها المجلدات الفرعية) وأفلتها.
   - اضغط **Commit changes**.
4. بعد الرفع، اذهب إلى تبويب **Actions** في أعلى صفحة المستودع.
5. سترى العملية **Build APK** تعمل تلقائيًا (أو اضغط عليها ثم **Run workflow** لتشغيلها يدويًا).
6. انتظر حتى تكتمل (دائرة خضراء ✓)، ثم افتحها واضغط على **app-debug-apk** أسفل قسم **Artifacts** لتنزيل ملف APK جاهز.
7. انقل الملف لهاتفك وثبّته كما في الطريقة الأولى.

> ملاحظة: هذا الملف الناتج هو نسخة **Debug** (للتجربة الشخصية والتثبيت المباشر)، وهي تعمل تمامًا كنسخة نهائية على جهازك. لو أردت نشر التطبيق لاحقًا على متجر Google Play فسيلزم توقيعه كنسخة Release منفصلة.

## استكشاف الأخطاء

**"Could not find or load main class org.gradle.wrapper.GradleWrapperMain"**
يعني أن ملف `gradle/wrapper/gradle-wrapper.jar` غير موجود بعد. هذا طبيعي عند أول فتح للمشروع؛ فقط اضغط **"Sync Now" / "Sync Project with Gradle Files"** من داخل Android Studio (أيقونة الفيل 🐘 في الأعلى) وسيُنزَّل تلقائيًا. لا داعٍ لأي أمر يدوي.

**أيقونة التطبيق لم تتغيّر فورًا بعد اختيار أيقونة جديدة من داخل التطبيق**
هذا طبيعي في بعض إصدارات أندرويد؛ النظام يحتاج أحيانًا بضع ثوانٍ لتحديث أيقونة الشاشة الرئيسية، أو قد تحتاج الرجوع للشاشة الرئيسية وإعادة فتح قائمة التطبيقات.

**الويدجت لا يعرض الساعة بدقة اللحظة**
أندرويد يفرض حدًا أدنى 30 دقيقة لتحديث الودجت الدوري (قيد نظام تشغيل، غير قابل للتجاوز إلا باستهلاك بطارية إضافي). الرسالة النشطة نفسها تتحدّث بدقة فورية عند كل تغيير فعلي بفضل نظام التنبيهات الداخلي، أما الساعة المعروضة فتتحدث كل نصف ساعة كحد أقصى بين التحديثات، وهذا اختيار مقصود لتوفير البطارية.

## هيكلة المشروع (لمن يريد التطوير لاحقًا)

```
app/src/main/java/com/schedmsg/app/
├── data/            # قاعدة البيانات المحلية (Room): النموذج، DAO، المستودع
├── util/            # منطق تحديد الرسالة النشطة، الوقت العالمي، جدولة التنبيهات، تبديل الأيقونة
├── receiver/        # استقبال إعادة التشغيل وتنبيهات النظام
├── widget/          # الـ Widget (Glance) وعامل التحديث في الخلفية
└── ui/
    ├── theme/       # الألوان والخطوط (هوية "ياسو المزة" البصرية)
    ├── components/  # عناصر واجهة قابلة لإعادة الاستخدام (بطاقة زجاجية، منتقي الوقت، تأكيد الحذف...)
    ├── screens/     # الشاشة الرئيسية، إضافة/تعديل رسالة، اختيار الأيقونة
    └── MainViewModel.kt
```

المنطق الأساسي لتحديد "الرسالة النشطة حاليًا" موجود في:
`app/src/main/java/com/schedmsg/app/util/ActiveMessageResolver.kt`

منطق الوقت العالمي (الأردن وسوريا) موجود في:
`app/src/main/java/com/schedmsg/app/util/WorldClock.kt`
